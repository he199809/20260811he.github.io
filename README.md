# Li He — Academic Homepage

This repository contains the academic homepage of Li He.

- Homepage: https://he199809.github.io/20260811he.github.io/
- Curriculum vitae: https://he199809.github.io/20260811he.github.io/cv.html

## Deployment

The site is deployed with GitHub Pages through the workflow in `.github/workflows/pages.yml`.
In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

The homepage is a static HTML site and requires no build step.
